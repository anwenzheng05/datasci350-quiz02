# TASK 6 wrote index.qmd 
---title: "Box Office Numbers"---This dataset contains 104 well-known films from 1980 to 2025. The data parameters include approximate budgets, worldwide revenues, runtimes, and ratings. The budget and revenue figures are approximate, rounded values in millions of US dollars and are not adjusted for inflation. The data are intended for classroom exploration rather than research.The website explore the analyses: [Budget and Revenue](budget-revenue.qmd), [Runtime and Ratings](runtime-rating.qmd), and [The Bond Films](bond.qmd).Aside from Lecture 10 and 11, I used AI agent Codex for assistance and debugging. 




# TASK 7 wrote budget-revenue.qmd, 
---title: "Budget and Revenue"---This page compares each film's production budget with its worldwide box-office revenue. The scatterplot @fig-budget-revenue shows that relationship across the films in the dataset.```{python}#| label: fig-budget-revenue#| fig-cap: "Production budget and worldwide revenue for 104 films (millions of US dollars)."#| echo: trueimport pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")plt.scatter(films["budget_musd"], films["revenue_musd"])plt.xlabel("Production budget (million USD)")plt.ylabel("Worldwide revenue (million USD)")plt.title("Film budget and worldwide revenue")plt.show()```



# TASK 8 wrote in runtime-rating.qmd, 
---title: "Runtime and Ratings"---Figure @fig-runtime-rating compares runtimes and IMDb ratings for the films. Each point represents one film.```{python}#| label: fig-runtime-rating#| fig-cap: "Runtime and IMDb rating for each film."#| echo: trueimport pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")plt.scatter(films["runtime_min"], films["imdb_rating"])plt.xlabel("Runtime (minutes)")plt.ylabel("IMDb rating")plt.title("Film runtime and IMDb rating")plt.show()```### Mean IMDb rating by decade```{python}import pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")films["decade"] = films["year"] // 10 * 10films.groupby("decade")["imdb_rating"].mean().round(2)```




# TASK 9 wrote in bond.qmd
---title: "The Bond Films"---```{python}import pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")bond = films[films["franchise"] == "James Bond"]```This page follows worldwide revenue across the James Bond films in the dataset. The films represented here span from `{python} int(bond["year"].min())` to `{python} int(bond["year"].max())`.```{python}plt.plot(bond["year"], bond["revenue_musd"], marker="o")plt.xlabel("Release year")plt.ylabel("Worldwide revenue (million USD)")plt.title("Worldwide revenue of James Bond films")plt.show()```
